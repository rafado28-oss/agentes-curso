18 de setembro de 2026

Manchete do dia: GitHub vai desligar cinco modelos do Copilot em 19 de outubro, o que obriga quem usa a ferramenta em aula a trocar de modelo antes da data.

Nas suas ferramentas: Atualização em Claude Code, GitHub Copilot, Gemini API e Grok Build; nada novo em Cursor.

Notícias

1. GitHub vai descontinuar cinco modelos do Copilot em outubro

A GitHub vai remover Gemini 3.7 Flash, GPT-5.5, GPT-5.4, GPT-5.4 mini e Grok 4.5 de todas as experiências do Copilot (Chat, inline edits, modos ask e agent) em 19 de outubro de 2026. As alternativas indicadas são Gemini 3.8 Flash, GPT-5.6 Sol, GPT-5.6 Luna e Grok 4.6; em contas Enterprise e Business a troca é automática, mas fluxos e integrações que dependem diretamente dos modelos antigos precisam ser atualizados antes do prazo.

Fonte: GitHub Changelog, 18/09/2026 — https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october/

2. Claude Code ganha suporte a AGENTS.md e corrige bug crítico de proxy

A versão 2.1.277 do Claude Code passou a suportar o arquivo AGENTS.md, melhorou o proxy gateway e corrigiu o erro "text content blocks must be non-empty". A versão anterior, 2.1.276, resolveu uma falha em que toda requisição retornava erro 400 quando ANTHROPIC_BASE_URL apontava para um proxy; as versões 2.1.275 e 2.1.274 trouxeram atalho send-now e sincronização de skills/plugins do claude.ai.

Fonte: Anthropic / Claude Code, changelog no GitHub, 18/09/2026 — https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md

3. Copilot code review passa a categorizar e resolver comentários sozinho

O resumo de revisão de código do Copilot agora separa os comentários em "Open", "Resolved since last review" e "Previously missed", cada um com título descritivo. O Copilot passa a resolver automaticamente seus próprios comentários conforme a resposta do desenvolvedor e a gerar título e descrição de commit quando um lote de sugestões é aceito; o recurso já vale para todos os usuários.

Fonte: GitHub Changelog, 18/09/2026 — https://github.blog/changelog/2026-09-18-copilot-code-review-an-improved-review-experience/

4. Gemini API atualiza o Antigravity Agent e desliga a versão anterior

O Google lançou o Antigravity Agent 09-2026 (antigravity-preview-09-2026) na API Gemini, substituindo o antigravity-preview-05-2026. Os parâmetros passam de snake_case para PascalCase e as edições de arquivo agora usam substituições por intervalo de linhas em vez de reescrever o arquivo inteiro; a versão anterior será desligada em 5 de outubro de 2026, o que exige migração de quem já integrou o agente.

Fonte: Google AI for Developers, changelog da API Gemini, 17/09/2026 — https://ai.google.dev/gemini-api/docs/changelog

5. Grok Build ganha memória entre sessões

O Grok Build, agente de código da xAI, passou a reter entre sessões as convenções, decisões e fatos do projeto, revisando o trabalho em segundo plano ao fim de cada sessão e guardando as anotações em markdown organizado por tópico. Dois comandos novos, /memory e /dream, permitem navegar e reorganizar essas anotações; o recurso já está disponível no Grok Build.

Fonte: xAI, 16/09/2026 — https://x.ai/news/grok-build-memory
