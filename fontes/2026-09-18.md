### 2. Introducing the Life Sciences Verification Program
- Link: https://www.anthropic.com/news/life-sciences-verification-program
- Veículo: Anthropic (blog oficial)
- Data da publicação: 2026-09-17
- O que a fonte diz:
  - Anthropic lançou o Life Sciences Verification Program (LSVP), dando acesso a modelos Claude (Mythos, Opus e Sonnet) com salvaguardas ajustadas para profissionais de ciências da vida.
  - O programa libera tarefas hoje bloqueadas nos modelos padrão, como descoberta de medicamentos, biologia de pesquisa, desenvolvimento clínico e manufatura, para organizações verificadas.
  - Há dois níveis de acesso: Standard Use (renovação anual, para a maioria dos trabalhos) e High-risk Use (renovação semestral, para projetos com maior risco de uso indevido); a verificação analisa credenciais de pesquisa e supervisão ética, com monitoramento offline; disponível em beta no console próprio, na API e nos planos Claude for Enterprise/Team.

### 3. Copilot code review: An improved review experience
- Link: https://github.blog/changelog/2026-09-18-copilot-code-review-an-improved-review-experience/
- Veículo: GitHub Changelog (GitHub/Microsoft)
- Data da publicação: 2026-09-18
- O que a fonte diz:
  - O comentário de visão geral da revisão de código do Copilot agora mostra três categorias: "Open" (itens não resolvidos, que podem ter o rótulo "new"), "Resolved since last review" e "Previously missed".

### 4. Upcoming deprecation of selected GitHub Copilot models in mid-October
- Link: https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october/
- Veículo: GitHub Changelog (GitHub/Microsoft)
- Data da publicação: 2026-09-18
- O que a fonte diz:
  - GitHub vai descontinuar cinco modelos em todas as experiências do Copilot (Chat, inline edits, modos ask e agent) em 19 de outubro de 2026: Gemini 3.7 Flash, GPT-5.5, GPT-5.4, GPT-5.4 mini e Grok 4.5.
  - Alternativas sugeridas pela GitHub: Gemini 3.8 Flash no lugar de Gemini 3.7 Flash; GPT-5.6 Sol no lugar de GPT-5.5 e GPT-5.4; GPT-5.6 Luna no lugar de GPT-5.4 mini; Grok 4.6 no lugar de Grok 4.5.

### 8. Memory in Grok Build
- Link: https://x.ai/news/grok-build-memory
- Veículo: xAI (blog oficial)
- Data da publicação: 2026-09-16
- O que a fonte diz:
  - O Grok Build ganhou um sistema de memória que retém entre sessões as convenções, decisões e fatos do projeto que surgem durante o trabalho; ao final de uma sessão, o Grok a revisa em segundo plano e registra as informações relevantes.
  - As notas ficam guardadas como arquivos markdown organizados por tópico, com escopo por projeto ou em configuração global; antes de iniciar um trabalho relacionado, o Grok lê os tópicos que cobrem aquela área.
  - Novos comandos: `/memory` abre um navegador das anotações armazenadas e `/dream` organiza anotações recentes em arquivos de tópico; o recurso já está disponível no Grok Build e passa a valer a partir de sessões novas.
